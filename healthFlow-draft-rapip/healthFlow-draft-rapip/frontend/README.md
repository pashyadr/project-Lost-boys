# healthFlow – Frontend (Expo)

Aplikasi mobile healthFlow: React Native + Expo SDK 58, TypeScript, Expo Router, NativeWind.

```bash
npm install
npx expo start --web    # preview di browser
npx expo start          # scan QR dengan Expo Go / development build
npx tsc --noEmit        # typecheck
npx eslint src          # lint
```

- Layar ada di `src/app/` (setiap file = satu layar).
- Komponen UI ada di `src/components/`.
- Token warna ada di `tailwind.config.js` dan `src/theme/tokens.ts`.
- Data di `src/data/` masih data contoh.

Info lengkap ada di [README utama](../README.md).
